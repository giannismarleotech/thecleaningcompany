# The Cleaning Company — website

Website voor **The Cleaning Company (est. by Hobi)**: zetel-, tapijt- en matrasreiniging aan huis, regio Gent.

- Online offerte-configurator (zetel / tapijt / matras) met live 3D-voorbeeld en vaste prijzen
- Foto-upload en aanvragen via Netlify Forms
- Resultaten-galerij (foto's + video's), Over ons, FAQ, contact

## Deploy
Statische site, klaar voor Netlify (`netlify.toml`, publish directory = root).
Prijzen en contactgegevens aanpassen: zie `TCC_CONFIG` en `PRICING` in `index.html`.

Gemaakt door [Marleo](https://marleo.tech).
